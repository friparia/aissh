# 桌面客户端与凭据管理

遇到堡垒机授权或其他需要人工输入的交互时，可点击 AI 输入区的「取消 AI，接管终端」，或在 CLI/终端按 `Ctrl+G`，然后直接输入所需内容（例如 `Q` 退出申请）。接管不依赖堡垒机提示文案，会取消本地 AI 等待并暂停主通道采集。此操作保留 SSH 连接，不主动发送 `Ctrl+C`，也不保证远端命令已停止。回到 Shell 提示符后可继续向 AI 提问；自动采集保持暂停，按刷新恢复。

兼容 OpenAI API 的 AI 配置支持「默认模型名称」和「可选模型」列表（每行一个，也可用逗号分隔）。连接会话后，在 AI 对话区域的「AI 模型」下拉框切换，后续请求使用所选模型并保留聊天上下文。当前选择随对话保存，重连和总结沿用；如果该模型已从配置中移除，重连使用配置的默认模型。AI 处理任务、执行命令或等待命令确认时暂时禁止切换。

## 从哪里开始

macOS 构建产物是 `dist/desktop/WRD AI SSH.app`。可直接双击，或复制到「应用程序」。首次运行创建空的本机配置，不导入或扫描你的密码。

macOS 构建的最低部署版本为 13.0，覆盖 13.7.8。Intel Mac 下载 `aissh-desktop-darwin-amd64`，Apple Silicon（M 系列）下载 `aissh-desktop-darwin-arm64`。Workflow 会校验 `.app` 和内置 CLI 的架构及实际最低系统版本；macOS 13 的运行体验仍需在对应系统上验证。

GitHub 的 [Build Desktop workflow](https://github.com/yuliyang2023/aissh/actions/workflows/desktop.yml) 构建 macOS、Linux、Windows 的 x86_64（amd64）和 aarch64（arm64）桌面 GUI。可通过 `gh workflow run desktop.yml --ref main` 手动触发，在运行记录的 Artifacts 中下载对应平台的压缩包和 `SHA256SUMS`。macOS 的 ZIP 包含 `.app`，Windows 的 ZIP 和 Linux 的 TAR.GZ 包含桌面程序及配套 CLI，解压后应保持包内目录结构。Linux 运行需要 GTK3、WebKitGTK 4.1；Windows 运行需要 WebView2。macOS 包使用本地临时签名，未进行 Apple 公证。

客户端直接进入统一工作区。最左侧是按服务器分组的 SSH + AI 会话列表，每项显示对话标题、摘要和连接状态；没有单独的「SSH 会话」管理页或第二份工作区列表。可搜索、折叠服务器分组，也可收起整个侧栏（记住选择）。运行中的会话点击即返回 AI / SSH / 监控工作区；离线会话先展示本机历史，点击「连接并继续」恢复所选上下文。查看历史不需要连接 SSH，历史命令建议不会再次执行。

新建会话的「已有连接」和「直接连接」都可选择 AI 配置：使用主机/默认配置、本机 Codex，或在「设置 → AI 配置」保存的兼容 OpenAI API 模型、Claude、DeepSeek、HTTP Agent。所选配置与对话一起保存，重连和总结沿用该配置；不修改已有主机的默认 AI 配置。选择 API 模型时不使用本机项目目录。旧对话未保存 AI 配置时，继续沿用原来的主机/默认配置。

左下角固定提供「外联系统」「本地知识」「设置」三个入口。「外联系统」管理系统说明、服务地址、关联主机和访问授权；「设置」管理主机、凭据和 AI 配置。管理页面保留会话侧栏，可点击「返回工作区」或直接选择会话，切换页面不会重启 SSH、清空终端或丢失尚未发送的 AI 输入。

「新建会话」也支持「直接连接」：填写地址、端口、SSH 用户名，选择已有登录凭据或当场新建，点击「连接并新建对话」即可进入工作台。没有预先配置主机也可以使用；首次连接仍需核对主机指纹。不绑定凭据时使用默认 SSH 密钥，或在终端输入密码。

「同时加入主机列表」默认不勾选。勾选后可以填写主机名称和分组；未勾选时，目标地址和凭据引用只随对话保留，不加入主机列表，重启后仍能预览和继续对话。密码仍由系统凭据库或 SSH 登录流程处理，不会写入连接信息或 AI 对话。

对话沿用 CLI 的本机历史存储，以主机配置 ID 隔离；断开连接、移除已结束的连接或重启客户端不会删除 AI 历史。新对话在第一条提问后自动使用问题作为标题。在终端内切换 AI 历史时，桌面端会同步关联。历史保留量沿用 CLI 的限制（默认每台主机最近 500 条记录），可通过 `AISSH_HISTORY_DIR` 指定目录；禁用历史时无法创建或恢复持久对话。

Codex 会话默认在退出时删除。在「设置 → AI 配置」编辑本机 Codex，开启「退出后保留 Codex 会话」后，下次连接创建的会话会保留，在线对话和离线历史提供「在本地 Codex 继续」及复制命令入口。退出后在同一台电脑、使用同一 Codex 配置运行 `codex resume <thread-id>`。切换新对话也会保留旧 thread；风险复核仍使用临时会话。此前已删除的 thread 无法恢复。

CLI 可用 `aissh --keep-codex-session sdp` 开启保留，或设置 `AISSH_KEEP_CODEX_SESSION=1`；`--no-keep-codex-session` 显式恢复删除行为。启动参数优先于环境变量和保存的 AI 配置。开启保留时，AI 对话会显示恢复命令并随本机历史保存，正常退出后也会在终端打印；重新进入 aissh 后可通过 Ctrl+R 选择历史查看该命令。关闭本机历史时，需要自行保存恢复命令。

1. 在「凭据」中添加账号密码、SSH 私钥引用、私钥口令、SSH Agent 或 API Token。
2. 在「主机」中填写地址、端口和账号，选择登录凭据。主机名称可留空，自动使用 `用户名@地址:端口`（用户名优先使用填写的账号，其次使用凭据账号；都未填写时使用 `地址:端口`），直接连接也遵循这一规则。分组、跳板机、AI 配置和本机工作区在「更多设置」中；需要跳板机时先添加跳板机，再绑定到目标主机。
3. 点击「测试连接」或「连接」。首次连接显示主机指纹，核对后才能使用保存的凭据。
4. 在「AI 配置」中选择本机 CLI，或填写模型 API 地址、模型名称和 Token 凭据。可设为默认，也可在每台主机中单独选择。
5. 在左下角「外联系统」中添加 API、数据库或 Redis，填写系统用途，绑定账号、关联主机和允许的操作范围。

界面支持跟随系统的浅色 / 深色外观。「设置 → 主机」可按主机分组、直接连接 / 通过跳板筛选，并组合搜索。macOS 保留系统菜单栏和标题栏习惯；`⌘N` 新建会话，`⌘,` 打开设置，`⌘1` 返回工作区，`⌘⇧N` 新建凭据，`⌘⌥S` 展开或收起会话列表，`⌘F` 聚焦当前会话 / 设置搜索。Windows / Linux 使用 Ctrl 修饰键。表单打开时，菜单不会打断当前录入。

连接工作台由可收起的会话列表、AI 对话区和 SSH 区组成。AI 区支持多行提问（Enter 发送，Shift+Enter 换行）、流式回答和带风险信息的命令审批；SSH 区保留终端交互，不绘制 `/sidebar`、AI 卡片或监控侧栏。窗口较窄时，两个工作区改为上下排列。折叠列表和切换会话都不会断开连接。

桌面 AI 回复按实际收到的增量持续显示，完成后在原消息内确认最终文本；连接中断时保留已经收到的内容并显示错误。工具调用和 SSH 命令默认收起为一行，状态及输出在原位置更新，点击可展开详情。向上翻阅对话时暂停自动跟随，点击「回到最新消息」恢复。

流式模式只在桌面工作台启用：Codex 使用独立的 `app-server` stdio 进程并在同一 SSH 工作区内复用；Claude 使用 `stream-json` 增量事件；直连模型使用 SSE。模型服务若返回普通 JSON，客户端仍能显示最终回答。独立命令行继续使用原来的调用与输出方式，命令执行仍经过已有审批流程。

AI 回复和历史对话支持 Markdown：标题、强调、嵌套列表、任务列表、引用、链接、表格、行内代码及代码块。回复流入时同步渲染，未闭合的代码块也可阅读；代码块保留缩进并提供复制按钮，长代码和宽表格可在各自区域内横向滚动。网页链接通过系统浏览器打开，图片引用显示为可打开的链接。

当前会话出现待确认命令时自动打开「命令审计」弹窗，展示执行目标、风险、说明、预期效果及完整命令。代码区提供 Shell 语法高亮、行号和浅色 / 深色配色，长命令可独立滚动、切换自动换行或原样复制；行号不进入复制内容，执行时使用原始命令。批准和拒绝操作固定在底部。按 Esc、关闭窗口或选择「稍后处理」会保留待审计命令，可点击「查看并审计」重新打开；后台会话的命令在切回该会话后展示。

SSH 终端保留最多 20,000 行回滚历史。在底部时自动跟随输出，滚轮上翻或拖动右侧滚动条后显示「浏览历史」，新输出不会将视图拉回底部；点击「回到底部」或手动滚到底部即可恢复跟随。按钮会将输入焦点交回终端，不向 SSH 发送命令。切换会话保留各自的浏览位置，会话结束后仍可翻阅；历史超过上限时最早的内容会被移除。

桌面终端直接呈现 SSH 输出，由客户端管理回滚；不会再嵌套命令行的全屏界面。SSH 区的中文、粘贴和远端程序鼠标操作交给远端终端，AI 提问使用左侧对话区。更新后需要重新连接 SSH，已有连接仍使用启动时的终端进程。

服务器监控位于工作区顶部，横跨下方的 AI 对话和 SSH 两栏，由客户端直接绘制。系统概览以横向卡片显示 1/5/15 分钟负载、内存、根目录磁盘和进程数；内存、磁盘带占用条。点击标题栏可收起为一行状态、负载和内存摘要，客户端记住折叠选择，下方对话和终端自动扩展。可切换到进程、磁盘、网络、服务，或添加符合原只读策略的自定义命令；AI 添加的监控也会同步出现。顶部「自动采集」默认关闭，开启后才会周期性运行远端采集命令；也可在 CLI 启动时传入 `--system-collection` 或设置 `AISSH_SYSTEM_COLLECTION=1` 开启。显示最近采集时间；采集失败时保留上次结果并显示错误，超过刷新间隔的三倍（至少 15 秒）标为过期。监控复用 aissh 现有采集器，不在远端安装程序。所有采集都在当前 SSH 终端运行；终端忙于交互时延后刷新。

开启自动采集后，内置默认监控免审批并静默运行；自定义脚本、告警任务和历史组件恢复中的自定义采集命令仍需命令审计。首次执行及命令、周期或 AI 读取范围变更时，弹窗展示完整脚本、执行目标和重复采集周期；`always-yes` 不会跳过这项人工审计。批准前不会试采，批准后按已审计配置重复运行，首次在 SSH 终端显示命令、实际输出和退出码，可从终端回滚记录查看，后续刷新仅更新监控面板；审计建议及批准/拒绝决定保存在会话历史中。拒绝后停止该配置，点击刷新可重新审计。批准仅对当前连接有效，重新连接和恢复历史组件中的自定义脚本需重新审计。

监控标题栏支持分级放大：点击「放大」将监控区扩至工作区约一半高度，AI 对话和 SSH 继续显示；再点击「最大化」占满当前工作区。两个放大档位都可直接点击「还原」，或在监控区内按 Esc，恢复原来的展开 / 收起状态。放大时保留当前监控项、自定义命令输入和实时刷新，长输出使用可用高度显示；最大化期间 AI 和 SSH 组件保留，会话不会重连，未发送的输入不会丢失。

Codex、Claude 与直连模型创建或更新监控时，提示词要求生成适合持续观察的等宽纯文本快照：简短标题和列名、必要单位与对象、稳定字段顺序，说明与建议放在对话中。筛选、Top N 或日志采样需标明范围及省略情况；用户要求完整输出时不得擅自截断，采集失败和缺失值不得显示为正常。此规则同时适用于新会话和继续已有模型会话，不会自动重写已有监控命令。

AI 提问和审批通过每个会话独立认证的本机通道传递，不通过模拟键盘输入发送到 Shell。审批携带当前建议 ID，并在发起审批和写入 SSH 前检查空闲提示符及未提交输入；过期操作会被拒绝。客户端显示最近 100 条运行时消息，较长消息截断显示；本机对话记录继续保存，用于离线预览和恢复上下文。独立命令行的 `/sidebar` 保持原有行为。

会话条目的关闭按钮或工作区右上角「断开连接」可结束连接，运行中的连接会先确认。已结束的会话可重新连接或移除，本机对话记录继续保留。最多同时运行 12 个连接、保留 50 个连接实例；已结束或启动失败的实例不占运行名额。

「运行中」表示本机工作台已启动，SSH 认证及远端连接结果以终端输出为准。重连使用当前主机配置并重新检查主机信任，恢复已有 AI 对话的上下文。退出客户端会终止当前连接，不会自动恢复远端进程。

SSH 异常退出时，会话历史会保存退出错误及最近 16 KiB 终端输出中的诊断（已知凭据脱敏），包括静默采集期间收到的断线信息。等待 Shell 空闲的周期采集会延后并标记旧数据过期，不反复生成失败采样。采集超时或手动中断后，先让终端回到空闲提示符并清空未提交输入，再点击监控「刷新」或告警「立即检查」恢复采集；无需为恢复暂停的监控重建仍然正常的 SSH 连接。

本机 Codex / Claude Code 使用其原有登录状态。若从 Finder 启动时找不到 CLI，可在 AI 配置中填写 CLI 的绝对路径。模型 API Key 通过「兼容 OpenAI API 的模型」或「DeepSeek」配置并保存在凭据库。HTTP Agent 也支持绑定 Bearer Token。

自定义模型服务和 HTTP Agent 地址支持 HTTP 或 HTTPS，包括非本机地址，例如 `http://192.168.1.100:8000/v1`。地址可包含路径，不接受内嵌账号密码、查询参数或片段。

桌面主机未设置「本机工作区」时关闭本机文件访问；选择目录后沿用 aissh 默认只读工作区策略。已有命令行用法及 `--workspace-write` 保持可用。

## 实时面板与告警监控

两类采集独立管理：

- **实时面板**位于会话工作台，只展示采集数据。系统概览默认显示但自动采集默认关闭；开启工作台顶部的「自动采集」后，才会周期性运行系统概览及已添加面板的远端命令。也可手动添加只读命令，或点「AI 添加面板」生成自定义采集。展开「采集配置」可查看实际命令与刷新周期。即使面板数据异常、过期或连接结束，也不会自动产生桌宠提醒。
- **告警监控**从左侧同名入口进入，右上角铃铛打开告警记录。点击「AI 添加告警任务」描述检查对象、周期与提醒条件；任务不会出现在实时面板标签中。清单显示所在会话、采集命令（已知凭据隐藏）、检查周期、最近采集时间、状态和异常条件，可搜索、筛选、复制命令、立即检查或停止并移除任务。

每个会话的 AI 对话标题栏也有「告警监控」入口，显示该会话的告警任务数量。点击后只查看当前会话的任务与问题记录，AI 添加任务时固定使用当前会话；连接已结束时可查看记录，但不能改用其他服务器创建任务。可通过「查看全部会话」返回总览。桌宠开关、提醒策略与静音仍是全局设置。

两类使用各自的 ID、命令、间隔和生命周期，各最多 16 个。查看同一个服务并配置异常提醒时会创建两个独立任务；关闭或刷新实时面板不会操作告警任务。两者都沿用当前 SSH 连接的只读采集通道，Shell 忙碌、AI 正在处理或执行命令时采集可能延后。切换页面、收起面板或最小化主窗口不会关闭告警判定；休眠、断开连接或退出客户端会停止采集。

告警项目不限于内置采集器，例如「每 5 秒检查 nginx，停止运行持续 10 秒通过桌宠提醒」或「接口响应高于 500 毫秒持续 30 秒提醒，回落到 400 毫秒后恢复」。AI 使用所选会话的配置，生成只读命令、检查周期及该任务的异常/恢复规则，信息不足时在对话中询问。可继续用自然语言修改或关闭 AI 创建的任务。命令和条件一起校验；创建成功不代表采集成功。只有真实采集结果参与判断，AI 展示文字不能制造异常或恢复。

「提醒策略」统一管理告警任务的采集失败、数据过期、SSH 断线，以及静音、重复提醒与恢复通知。业务指标的阈值和异常/恢复持续时间由各个任务单独配置，不从实时系统概览自动产生内存、磁盘或负载告警。旧版全局指标阈值会退出使用，其他提醒偏好保留；需要这些提醒时通过 AI 创建独立任务。默认采集/断线异常持续 10 秒触发、恢复持续 10 秒确认，同一问题每 5 分钟重复；数据过期默认 30 秒且至少为该任务间隔的 3 倍。缺失、失败、重复或过期数据不作为新的正常采样。

「问题记录」显示当前问题与最近 100 条已结束记录。「我知道了」停止该问题的重复提醒；「静音 15 分钟」保留判定和记录，暂时关闭提醒。停止任务、修改采集命令或移除会话后，对应旧问题标记为「已停止监控」，不伪造恢复。全局策略保存在本机 `monitor-alerts.json`；任务配置、问题记录和临时静音仅本次运行有效，重新连接后需重新创建任务。

在「告警监控」点击「开启桌宠」打开可拖动、置顶、透明背景的像素小猫，接收告警任务的异常与恢复消息，也会在会话中的 AI 任务完成后弹出「任务完成啦」。命令只在需要人工评审确认时提醒，点击气泡返回对应会话查看命令并决定是否执行；自动风险复核和命令开始执行时不另行提示。任务失败或需要补充信息时会显示对应提示；仍在执行、自动确认流程中或取消的任务不会误报完成。无需添加告警任务也能收到 AI 任务提醒，点击气泡返回对应会话查看结果。

多会话提醒显示主机名称和会话短标识，可区分同名主机上的不同连接。桌宠下方显示「N 个会话 · M 条未读」，点击可展开可滚动的未读列表，异常和待处理事项优先；点击列表条目直接回到对应会话。气泡内可用「上一条／下一条」切换，或点「全部提醒」查看列表，新会话的提醒不会打断正在阅读的那一条。同一会话的新任务结果替换旧提示，监控告警按问题分别保留。

气泡约 20 秒后自动收起，手动收起和超时均保留未读；鼠标停留或键盘聚焦时暂停收起，列表不会自动关闭。点击查看会话、在前台实际查看对应会话，或点击「已读」「全部已读」后清理相应未读，不会因轮询重复弹出；后台会话和不可见的对话保持未读；标记桌宠已读不会停止后台监控或执行任务。未读列表在本次桌宠运行中保留最近 50 条，隐藏或重启桌宠会清空。没有未读时点击状态文字打开告警记录。任务提醒沿用全局提醒开关与静音，关闭提醒或静音会清空当前未读，期间完成的任务不会在恢复提醒后补弹。

小猫会眨眼、摆尾，并按守护、休息或异常切换表情；系统开启「减少动态效果」时停止动画。鼠标靠近小猫或用键盘聚焦时显示操作按钮，支持临时静音和隐藏，隐藏不停止任务，退出客户端同时结束小猫。开启偏好会在下次启动时恢复。小猫通过带随机令牌的本机通道接收摘要，AI 任务提醒只包含结果状态与会话名称，不传输对话、命令或执行输出，没有凭据读取或 SSH 命令执行接口。

当前告警依赖客户端与 SSH 连接，不是脱离客户端运行的服务。macOS 桌宠使用独立辅助进程，配置为跨 Spaces、全屏辅助窗口，并在 macOS 13+ 加入其他应用的台前调度分组；切换应用不隐藏，透明窗口不带磨砂底板和系统阴影。Windows / Linux 保留原有置顶配置；各平台实际桌面切换、全屏和拖动体验仍需在目标环境验收。

桌宠支持「监控橘猫」「黑客猫猫」和「太空猫猫」三种样式。在「告警监控 → 桌宠样式」选择并预览，或点击小猫下方的换装按钮按上述顺序循环切换，正在显示的告警气泡会保留。黑客猫猫穿深色连帽衫，抱着迷你终端，荧光绿眼睛随告警变为黄色或红色，休息时闭眼、屏幕变暗。太空猫猫戴浅蓝透明头盔、穿奶白色太空服，带小行星和推进器，值班时轻轻悬浮；告警时头盔与胸前指示灯变色，休息时闭眼并关闭推进器。所有动画遵循系统「减少动态效果」设置。样式保存到本机配置，重启客户端后恢复；旧配置默认使用监控橘猫。

## 本地知识与数据表

左下角「本地知识」保存三类资料，可按类型筛选、搜索标题/标签/正文/单元格，并关联到系统或主机：

- **文件文档**：选择本机文本、PDF 或 Office 文件，也可保存在线文档链接。保存的是文件引用，原文件留在原位置；256 KB 以内的 UTF-8 文本会带入可搜索的正文，PDF/Office 等文档通过系统默认应用打开，也可补充文字说明。移动原文件后需要重新选择。
- **经验总结**：手动整理经验，或从知识库的「从会话总结」/工作区的「总结到知识库」生成草稿。使用来源主机的 AI 配置（其次是默认配置，未配置时为本机 Codex），生成过程不连接 SSH。会话内容发送给所配置的 AI 后端；总结保留来源会话，区分建议与已验证结果，编辑后点击保存。超长会话只使用最近 128 KB 的完整消息，并在来源中标明。该功能由用户点击触发，不会后台自动归档每次对话。
- **数据表**：用于在线 Excel、CMDB 等通用表格资料，自定义列名、增删改记录、搜索任意字段。支持导入 UTF-8 CSV/TSV，或将 Excel/在线表格区域（含首行列名）粘贴到草稿中；最多 50 列、5000 条记录，导入文件最多 8 MB。可保留在线来源链接，数据作为本地副本维护；来源变化后重新导入/粘贴，应用表格会替换草稿中的表格，保存后才生效。当前不自动同步在线 Excel/CMDB，`.xlsx` 可作为文档引用，表格数据请通过复制区域或 CSV/TSV 导入。

新建外联系统或本地知识时，可以切换到「与 AI 对话创建」。这是一段独立的创建对话，使用默认 AI 配置（未设置时使用本机 Codex），无需建立 SSH 会话。例如说「192.0.2.10 属于研发部」，AI 会查询已有资料、选择或建立通用数据表并自动保存该记录；也可以整理业务台账、资产信息和明确要求保存的经验。保存成功后窗口显示实际保存回执，点击「完成」返回列表，不需要再点表单保存。必要信息不完整时可继续对话补充，切换到表单会保留当前草稿和对话。

创建工具只写入本机资料：按定位字段追加或更新单条数据，重复事实不重复追加；修改已有不同值前需读取版本，过期更新会被拒绝。对话写入的知识保留最近 100 条原话与变更记录，详情中可查看最近 10 条。外联系统的新建配置不含凭据，创建后可在表单中绑定；已有系统可通过对话更新名称和说明，地址与授权变更在表单处理。对话内容以及 AI 查询到的本地资料会发送给所选 AI 后端。在线 Excel/CMDB 链接仍是资料来源，本功能不会回写或同步在线表格。

知识条目单独保存在配置目录的 `knowledge.json`，文件锁与原子替换避免中断写入，多窗口过期编辑/删除会被拒绝。删除主机或系统保留其已有知识；删除知识条目不删除原始文件、在线资料或会话记录。知识库总大小限制为 32 MB，单条正文最多 256 KB，单元格最多 8 KB。普通保存不会自动上传资料，也不会自动注入 SSH 会话；AI 创建和总结仅在用户发起时使用相关资料。

## 跨平台分层

沿用 Wails 桌面壳，界面资源随应用本地打包。React 负责导航、列表、搜索、表单和终端显示；Go 服务负责配置校验、授权、凭据读取、SSH 会话与隧道、系统适配器和本机 AI 进程；系统接口负责窗口、菜单、文件选择和各平台凭据库。业务界面在三个平台复用，标题栏与快捷键遵循平台习惯。

录入秘密时，表单短暂持有用户输入并通过受限服务方法提交；读取配置只返回元数据与 `hasSecret` 状态，不向界面返回已保存的秘密，也不提供通用的秘密读取接口。连接、资源访问和 AI 调用都由 Go 层按配置引用取用凭据。后续增加通知、托盘等系统联动时，放在平台适配层，避免业务界面依赖某一操作系统。

界面跨平台复用不代表系统集成已经在各平台完成验收；Windows / Linux 仍需要原生运行环境检查窗口、SSH、凭据库及打包行为。

## 系统连接怎样使用凭据

架构和实现细节见[外联系统与接口调用架构](external-systems-architecture.md)及[当前实现说明](external-systems-implementation.md)。

添加连接时选择所属系统、环境、服务地址、凭据及网络路径。保存会启动后台只读探索：HTTP 读取当前服务内的 OpenAPI / Swagger JSON；数据库使用只读事务读取表字段；Redis 读取 INFO。探索不会试执行业务接口，不会产生业务调用授权。探索失败保留连接，可取消或重试；重启后未完成的任务会显示为中断。

打开「操作目录」管理五部分：

- **接口目录**：审查发现的候选接口，补齐输入 Schema、固定请求模板、读写效果与风险后启用。接口修改产生新版本，已有授权不会自动升级。文档变化使对应接口重新进入待审查状态。
- **权限管理**：连接能力上限 + 指定主体的接口版本授权。主体支持本机、SSH 主机或单会话；可限定参数值、前缀、数量、输入字段、生效/到期时间和使用次数。显式拒绝优先，写权限不自动包含删除、服务操作或远端权限管理。
- **风险规则**：独立设置敏感操作、删除、高风险和严重风险限制，生产写入下限及响应、行数、超时上限。风险规则不能替代授权；写操作始终逐次确认。
- **预览与调用**：本地预览权限决策、风险原因和准备好的实际请求。桌面执行按本机主体授权；选择 SSH 主体只模拟规则。确认令牌绑定参数、连接、凭据、接口与策略版本，有效期五分钟且只能用一次。
- **审计记录**：查看调用发起、完成/失败/不确定结果和配置变更。仅保存请求摘要、版本与决策，不保存凭据或业务响应。进程中断后只有发起记录的写请求同样需要先核对外部状态。

| 类型 | 当前支持的已登记接口 | 认证 |
| --- | --- | --- |
| HTTP | GET / HEAD / POST / PUT / PATCH / DELETE，固定连接内路径、标量路径/查询参数、JSON 请求体；不跟随重定向 | Basic / Bearer |
| PostgreSQL | 参数化 SELECT；事务内 INSERT / UPDATE / DELETE，影响行数超过上限时回滚 | 用户名 / 密码 |
| MySQL | 参数化 SELECT，只读事务，禁用多语句；写操作暂不开放 | 用户名 / 密码 |
| Redis | 内置读取命令；已登记的单键 SET / EXPIRE / PERSIST / DEL / UNLINK；清库、脚本、配置与停机命令不开放 | 密码或 ACL 用户名 / 密码 |

接口 Schema 使用明确的受支持子集；不能理解的约束、引用和参数位置会阻止调用，需要人工补齐。数据库接口必须保存固定 SQL 和参数顺序，业务调用不接收模型临时生成的 SQL。默认返回最多 100 行 / 128 KiB，超时 30 秒，可在风险规则内收紧。字段范围约束针对输入，响应字段范围应由固定 SQL 投影或 HTTP 接口本身保证。

SSH 隧道使用 OpenSSH direct-tcpip，不开放本机监听端口、不在远端安装代理；隧道主机仅决定网络路径，调用主体另行授权。TLS 校验目标系统主机名。凭据在权限、风险和确认检查通过后才读取，不拼入 AI 生成的 Shell。

首次管理旧连接时创建独立目录并备份 v1 配置，再启用 v2 门禁；旧客户端会拒绝读取新配置。旧授权只迁移到内置只读接口，发现的业务接口需要重新审查和授权。`--always-yes` 不能绕过这些检查。所有业务调用使用 `system.invoke`，旧的 `http.get`、`database.query` 和 `redis.read` 不再作为公开执行入口。

## 命令行与本机工具

桌面端和 CLI 使用同一份配置。配置 ID 可以从 `connections.json` 中读取，它只含元数据。

```bash
# 使用保存的主机和 AI 配置
aissh --profile HOST_ID
aissh --profile HOST_ID --ai-profile AI_PROFILE_ID

# 读取本地接口目录及确切输入要求
aissh --resource '{"resourceId":"RESOURCE_ID","action":"system.describe"}'

# 调用已登记并授予本机低风险只读自动权限的接口
aissh --resource '{"resourceId":"RESOURCE_ID","action":"system.invoke","operationId":"OPERATION_ID","operationRevision":1,"arguments":{}}'
```

非交互本机工具需要对应接口版本的本机授权，且风险规则允许自动读取。它不能通过 JSON 传入批准标志、目标 URL、另一台 SSH 主机或任意请求头。需要逐次审批时，在桌面或交互式 aissh 中操作。

`--profile` 不接受额外 SSH 地址、参数或 `--ssh-path` 覆盖；保存的 AI 配置会同时决定服务地址和凭据，避免地址被命令行覆盖后把秘密发送到另一个服务。原有 `aissh user@host` 仍使用原生 SSH 参数；配置了默认 AI 后端后也会复用该配置。

## 保存、更新与恢复

| 数据 | 位置 |
| --- | --- |
| macOS 连接配置 | `~/Library/Application Support/aissh/connections.json` |
| Linux 连接配置 | `$XDG_CONFIG_HOME/aissh/connections.json`，默认 `~/.config/aissh/` |
| Windows 连接配置 | `%AppData%\aissh\connections.json` |
| 本地知识、文档引用与数据表 | 连接配置同目录 `knowledge.json` |
| 主机信任记录 | 同目录 `known_hosts`；也读取用户已有的 SSH 主机信任记录 |
| 密码 / Token / 私钥口令 | macOS Keychain、Windows Credential Manager、Linux Secret Service |
| SSH 私钥 | 原有文件或 SSH Agent，客户端只保存引用 |

`AISSH_CONFIG_DIR` 可以指定独立配置目录。OS 凭据服务标识是 `com.wrdtech.aissh.credentials`。配置通过文件锁和原子替换保存；Unix 下目录权限 0700、文件 0600。Windows 下沿用用户配置目录的 ACL。

编辑已有凭据时，秘密字段留空表示保留，输入新值表示轮换。删除仍被引用的凭据会被阻止。轮换时先保存新秘密和引用，再清理旧项；系统凭据库锁定导致的清理失败会显示「清理旧凭据」入口。

桌面连接进行中，如果已保存的秘密不可读取，会弹出凭据更新窗口；更新或解锁后继续原任务。密码被服务器拒绝时不会反复提交旧密码，请编辑凭据后重新连接。MFA / keyboard-interactive 不自动代填。

配置文件备份不包含密码；迁移到其他设备后需要重录秘密并重新选择私钥。首版不提供云同步、团队共享、密码明文导出或自建主密码保险库。

主机公钥变更时 OpenSSH 会拒绝连接。请先通过可信渠道核对变更，再手动更新对应 `known_hosts` 条目；客户端不会自动覆盖旧指纹。SSH 配置导入目前只导入名称、地址、端口、用户，导入后需核对私钥和跳板机绑定。

保存的主机连接会按其地址匹配 `~/.ssh/config` 的 `Host` 规则，例如地址 `server.xxx.com` 会使用 `Host *.xxx.com` 下的 `ProxyCommand`。无需在客户端重复填写代理命令。客户端保存的地址、端口、账号、凭据和跳板机设置优先；其余选项由系统 OpenSSH 解析。导入后若地址已变成 IP，原来按域名或别名匹配的规则不会命中，应在主机地址中保留需要匹配的域名。首次指纹检查也使用相同代理和跳板路径，不要求跳板机安装 `ssh-keyscan`；候选公钥只写入临时文件，用户确认后才保存信任记录，检查阶段不向目标主机发送密码或私钥认证。

AI 请求、aissh 聊天记录和适配器返回值会过滤当前已读取的秘密及常见编码形式。这不能识别所有未知秘密或任意编码；远端输出和本机 CLI 自身的记录仍遵循各自的数据处理规则。OS 凭据库也不隔离已经取得当前用户权限的恶意程序。

## 构建与验证

AI 自定义实时看板的使用、保存/版本回退及测试说明见 [自定义监控组件](custom-monitor-components.md)。

需要 Go 1.25+、Node.js 20+、npm。首个构建下载 Go 和 npm 依赖。

```bash
go test ./...
make desktop
```

- macOS：需要 Xcode 命令行工具。构建生成当前架构 `.app`，内含配套 CLI，并使用本机临时签名；面向其他用户分发前需要正式签名和公证。
- Windows：运行 `powershell -File scripts/build-desktop.ps1`，保持两个 `.exe` 在同一目录。需要系统 OpenSSH Client 和 WebView2 Runtime。
- Linux：需要 GTK3 和 WebKitGTK 开发包、图形会话与已解锁 Secret Service。发行版提供 WebKitGTK 4.1 时，可通过 `GOFLAGS=-tags=webkit2_41` 构建。
- 安装过前端依赖后，可以设置 `AISSH_SKIP_INSTALL=1` 跳过 `npm ci`。`GO`、`NPM` 支持指定工具路径（Windows 脚本使用 PATH 中的 npm）。

```bash
# 竞态与回归测试；SSH 集成测试需要系统 ssh 和本机临时端口
go test -race -p 2 ./...

# 实测 OS 凭据库，只操作独立测试服务中的随机条目并自动删除
AISSH_TEST_OS_KEYRING=1 go test ./internal/catalog -run TestOSKeyringRoundTrip -v

# 界面流程测试：需先构建 frontend，并安装 Playwright 和 Chrome
# 可通过 PLAYWRIGHT_MODULE / CHROME_PATH 指定现有安装
node scripts/test-desktop-ui.mjs

# 只验证 SSH 终端滚动、跟随、切换会话与窗口缩放
TERMINAL_ONLY=1 node scripts/test-desktop-ui.mjs

# 用真实终端进程输出验证滚动条（Unix；SSH 使用测试替身，不连接实际主机）
AISSH_TEST_DESKTOP_TRANSCRIPT="$PWD/.cache/desktop-terminal.ansi" go test ./internal/app -run '^TestDesktopTerminalPTYScrollback$' -count=1
TERMINAL_ONLY=1 TERMINAL_TRANSCRIPT="$PWD/.cache/desktop-terminal.ansi" node scripts/test-desktop-ui.mjs
```

本次开发验证了 macOS 原生窗口、真实 Keychain、真实 OpenSSH 密码/加密私钥认证、跳板机与隧道、授权和脱敏，以及浏览器中的完整界面操作。界面自动化使用内存 Wails bridge，真实窗口启动另行验证。Windows/Linux 的桌面交互及你的实际业务数据库仍需在对应环境验收。
